# 项目全貌

系统链路：INMP441 采集 16kHz 音频 -> 电脑中转服务 -> 百炼 ASR -> 千问模型（提示词从固件读取）-> 按句切分 -> 百炼 CosyVoice TTS -> 24kHz PCM 回传 -> ESP32 音频队列与 I2S -> MAX98357A 喇叭。屏幕采用内存画布整帧刷新，用户和回复按句显示；回复结束后自动进入下一轮聆听。

固件中的 GPIO、情绪标签、语速映射、按键和原提示词均保留。中转服务只过滤控制标签，密钥集中放在本地文件。

注意：TTS 首声延迟受网络和云端影响；音频杂音优先检查 5V 电源纹波、I2S 地线、功放扬声器走线和 USB/功放共地。TF 卡 UI 图片不在本归档中，需从设备导出。
