# 换电脑迁移步骤

先复制整个 `xiangmuA`，不要只复制 ino 文件。Arduino 中选择 ESP32-S3 Dev Module，并按原工程选择 N16R8、OPI PSRAM 等选项。安装 ESP32 Core 3.3.x 和工程使用的显示屏、SD、WebSockets 等库。

中转服务在 `relay-server` 执行 `py -3 -m venv .venv`、`.venv\Scripts\pip install -r requirements.txt`，再运行 `start_relay.ps1`。电脑和 ESP32 必须在同一局域网，防火墙放行 TCP 8000。

若换网络，先用 `ipconfig` 查看电脑 IPv4，把 `secrets.local.h` 中的中转 IP 改为新地址并重新烧录；WiFi 名称和密码也在该文件修改。
