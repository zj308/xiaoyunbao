# 换机配置模板与操作

## 固件密钥

`02_主程序/SmartCompanionS3/secrets.local.h` 已按本机原中转和云端配置写好，打开工程即可编译。Wi-Fi 用手机配网。不要把该文件上传或发给队外人员。

## 本地中转

在 `relay-server` 目录创建 Python 3.10/3.11 虚拟环境，安装 `requirements.txt`，再运行 `start_relay.ps1`。ESP32 和电脑必须在同一局域网，换网络后用 `ipconfig` 查看电脑 IPv4，并同步修改固件密钥中的中转地址。

## 云服务器

公网服务器地址是 `47.95.194.77`，systemd 服务是 `xiyunbao-relay.service`。服务端音色配置位置为 `/opt/xiangmuA/relay-server/data/.config.yaml`。修改后重启服务并用 `systemctl is-active xiyunbao-relay.service` 检查。SSH 密码不放入本文件。

## TF 卡

将 `firmware/SmartCompanionS3/data/` 内容复制到 TF 卡根目录对应的 `/ui/` 目录。TF 卡使用 FAT32，CS 接 GPIO15。动画文件必须保持固件使用的文件名和大小写。

## 烧录

优先使用 `firmware/SmartCompanionS3-v94-animation-audio-fix-longtongxuxian-16MB.bin`。若重新编译，在 Arduino IDE 中打开 `SmartCompanionS3.ino`，选择 ESP32-S3 Dev Module、16 MB Flash、`app3M_fat9M_16MB`，编译并烧录。烧录前关闭电池总开关，只连接开发板 USB；烧录后打开串口监视器，波特率按源码设置。

v94 修复：动画帧只刷新数字人物区域，不再覆盖蓝色气泡、标题和聆听白点；INMP441 固定声道并增加直流滤除、噪声底估计、噪声门和 180 ms 尾音保持。若实际 INMP441 的 L/R 接 3.3V，将源码 `MIC_USE_RIGHT_CHANNEL` 改为 `true` 后重新编译。
