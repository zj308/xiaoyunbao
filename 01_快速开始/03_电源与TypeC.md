# 电源与 Type-C（开发板方案）

## 正确电源路径

`锂电池 -> TP4056 B+/B- -> TP4056 OUT+/OUT- -> 总开关 -> MT3608 VIN+/VIN- -> 调到 5.0~5.2V -> SS34 -> 5V_RAIL`

`5V_RAIL` 接开发板 5V 针、MAX98357A VIN、AMS1117-3.3 输入。AMS1117 的输出命名为 `3V3_AUX`，只给 TFT、TF 卡和 INMP441 等外设供电，不与开发板的 3V3 针硬并联。所有 GND 必须共地。

SS34 的方向是：阳极 A 接 MT3608 输出，阴极 K（有色环一端）接 5V_RAIL。这样电脑 USB 给开发板供电/烧录时，5V 不会倒灌回 MT3608 和 TP4056；电池供电时也能从开发板 5V 针给开发板供电。

AMS1117 输入侧放 10uF + 100nF，输出侧放 22uF + 100nF。MAX98357A 附近的 5V_RAIL 放 470~1000uF 电解电容和 100nF 陶瓷电容。

## Type-C 的作用

烧录和电脑供电直接使用开发板自带的 USB 口，不在转接 PCB 上重复画 USB-C、CH343、D+/D-、BOOT 或 RESET 电路。GPIO19/20 留给开发板原生 USB。

TP4056 自带的 Type-C 只负责给锂电池充电，不能用于烧录 ESP32。

烧录调试时可以关闭电池总开关，只插开发板 USB。USB 会给开发板和 5V_RAIL 上的外设供电；SS34 阻止电流倒流进 MT3608。首次焊接后先不插模块，测 5V_RAIL、3V3_AUX 对 GND 无短路，再限流上电。

## 不能这样接

- 不把 MT3608 输出直接和 USB 5V 硬并联，必须经过 SS34。
- 不把 AMS1117 输出和开发板 3V3 输出并联。
- 不给 GPIO 或 INMP441 输入 5V。
- 不把 MAX98357A 的 SPK- 接系统 GND；喇叭两根线都只接功放输出端。
- 不用外置 USB-C 重复连接 GPIO19/20。
