# 对话决策记录

- Wi-Fi 改为手机配网写入 NVS，不再要求代码里固定 SSID/密码；GPIO21 长按重新配网。
- 音色最终固定为 `qwen-audio-3.0-tts-flash-longtongxuxian`，服务器和固件都要一致。
- 主程序 GPIO 保持原样；摄像头先使用独立工程和不冲突的 GPIO，禁止直接塞进主程序。
- 摄像头 BY-OV2640-V1.5 使用板载 Y1 晶振，XCLK 不接；PWDN 接地、RST 接 3.3V。
- GPIO48 为板载 RGB 灯脚，HREF 改为 GPIO46；SCCB 为 SDA=1、SCL=2。
- UI 要求动画只刷新上半区，气泡和文字独立刷新；中文逐字符测宽并稳定换行；未唤醒显示“请唤醒我开始交流”；聆听白点在气泡下方。
- 解决过启动慢、启动花屏、动画缺帧、按键难触发、扬声器杂音、服务器音色未同步和 `secrets.local.h` 缺失等问题。
- 竞赛方案采用云伴 CampusCare，多模态情绪线索只作辅助，不作医疗诊断。
