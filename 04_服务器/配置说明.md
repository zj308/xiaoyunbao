# 中转服务器配置说明

服务器代码在 `relay-server`，运行时配置不随交接包提供。服务器上的实际配置通常为 `/opt/xiangmuA/relay-server/data/.config.yaml`。

音色修改：编辑 `tts_voice` 为 `qwen-audio-3.0-tts-flash-longtongxuxian`，保存后执行：

```bash
systemctl restart xiyunbao-relay.service
systemctl is-active xiyunbao-relay.service
```

只复制命令行，不复制 Markdown 的 ```bash 围栏。服务 active 只说明进程运行，仍需查看日志确认 TTS/ASR provider、端口和 WebSocket 握手。API Key、Wi-Fi 密码、relay secret 不写进本文件；使用 `relay-server/data/.config.yaml.example` 生成本机配置。
