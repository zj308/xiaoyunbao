# 立创板子 v103 DRC / 铺铜检查报告

原文件未改：`立创板子.epro2`  
修改副本：`立创板子-v103-drc-fix.epro2`

## 满屏报 GND 的原因

铺铜网络已经是 `GND`，不是绑错网。

真正的问题是：**板框和铺铜画在 Y≥0，全部器件、走线、过孔在 Y≤0。**  
铜皮铺在空矩形里，GND 焊盘碰不到地铜，DRC 就把几乎所有地网络标成未连接 / 死铜 / 间距错误。

另外只有顶层铺铜，底层没有 GND 平面。

## 已改内容

| 项 | 原状态 | 修改后 |
|---|---|---|
| 板框 | `(0, 0)` 向 +Y，约 54.7×64.6 mm，与电路不重叠 | 同一尺寸移到 `(0, -64.6 mm)`，包住全部走线/过孔 |
| POUR1 | 顶层 GND，区域与错误板框重合 | 仍绑 `GND`，内缩 0.3 mm，覆盖电路 |
| POUR2 | 无 | 底层 GND，同样范围 |
| 旧铺铜填充 | 只在原点附近约 12×12 mm 的碎铜 | 已清空，导入后需重建 |

板内已有 **150 个 GND 过孔**，分布覆盖整个电路区。底层铺铜重建后，这些过孔会把两面地连起来。

## 检查结果（文件级，不是嘉立创 DRC 引擎）

- 原理图与 PCB 主要位号一致：U1/U2/U3/U5、C1–C8、H3–H11、SCREW2–4。
- 电源网：`GND`、`5V`（约 1.0 mm）、`3V3`（约 0.6 mm）。
- 过孔：钻孔 12 mil / 外径 24 mil，符合嘉立创常规能力。
- 单地平面，无 AGND/PGND 混接。
- 铺铜 `keepIsland=false`，间距 0.2 mm。

## 做不到的保证

**不能保证打板后一定稳定。** 嘉立创不会在导出文件里保存一份可离线重跑的完整 DRC 结果。铜皮几何必须在专业版里点「重建铺铜」后才算数。

上电前仍需要：万用表查 5V/3V3 对地是否短路、极性、限流上电、测 USB 枚举和麦克风/功放。

## 导入后请你做的 4 步

1. 嘉立创专业版：**文件 → 导入 → 工程**，打开 `立创板子-v103-drc-fix.epro2`（不要直接覆盖云端原工程，先另存/导入成新项目）。
2. PCB 里选中铺铜 → **重建铺铜**（顶层 POUR1、底层 POUR2 都要重建）。
3. **设计 → DRC**。GND 未连接/死铜应明显下降；若还有个别报错，点进去看是间距还是未布线。
4. 核对无 error 后再出 Gerber。下单前确认铜厚：工程规则里 **2oz 处于 NORMAL**，若你只要 1oz，在规则里改回 1oz 再出 Gerber。

## 假设与待确认

- 板框尺寸保持你原来的 54.7×64.6 mm，只平移到电路所在象限。
- 电容位号在 PCB 上没有 Value；原理图里部分是 10µF，请按实际物料核对。
- 存在空网络 `""` 和 GPIO 网 `0`（这是 IO0，不是地）。
- 没有 H1/H2、U4、SCREW1，按现有原理图这是缺号不是丢件。
- 这是模块载板（ESP32-S3 开发板 + INMP441 + 排母），稳定性和接触、供电、天线净空有关，不只取决于铺铜。
